# 能力方式 × 证据矩阵

目标 R01—R22 完整保留于 REQUIREMENTS。复合要求不因一个子功能存在就整项 PASS。本轮不计总分、不设伪精确权重/覆盖率；许可证、身份/权限、数据精度、发布恢复不能由 UI或热度抵消。

缩写：`CN=COMMUNITY_NATIVE`，`OC=OFFICIAL_COMMERCIAL`，`EX=CUSTOM_EXTENSION`（仅有具体扩展接口/方案，不代表已实现），`CR=CORE_REWRITE`，`NO=UNSUPPORTED`，`U=UNKNOWN`。证据：`D=DOC_ONLY`，`S=SOURCE_TRACED`，`T=EXISTING_TEST_FOUND`，`V=RUNTIME_VERIFIED`，`B=BLOCKED`。

`U/—` 表示事实状态 **UNVERIFIED、没有可归入上述等级的有效需求证据**，不是新增通过等级，也没有伪造 DOC_ONLY 或将未深读称为网络 BLOCKED。已找到部分 source 的需求仍可整体 UNKNOWN。`V*` 只指 ObjectStack 已发行 17.7.0 的 standalone/PG 两场景，源码→二进制等价未证实，不含认证、HTTP/MCP/UI。负面观察也可属于 V，不能把证据级别当能力通过。
