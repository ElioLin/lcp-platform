# 固定提交审查协议

本协议可用于后续每轮；本轮**已填写审查请求**在实际PR正文、最终回复与忽略的`artifacts/handoff/PLAT-000-PRE-review-request.md`，不使用本文件代替最终请求。

审查请求必须具体填写仓库、PR、分支、报告Base/Head完整SHA、需求/报告路径、未提交修改、各candidate版本/SHA、主要永久证据、实际运行范围、未验证/阻塞、路线理由与待批准变化。不要求审查“最新分支”。最终Head不写入含它自身的提交文件。

审查者先确认访问范围，再核对原始任务/R01—R22与关键上游：runtime对象与生成代码、真实后端权限与UI隐藏、MCP Server/Client、source/正式发行/实验/商业模块、许可正文与场景、扩展还是core rewrite、身份/事务/迁移/退出、真实运行/mock/doc、成本/搜索范围与环境保护。

输出必须有：实际审查范围及访问限制；已证实/修正/证据不足；重大缺陷的来源/条件/影响/补证；是否认可路线及适用条件；能否进入采用/自建讨论（不授权开发）；如需修正，给出有界Codex Prompt并要求再次输出固定提交审查请求。访问失败时明确缺失，不凭开发者总结完整通过。
